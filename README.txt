To run the project, first run the part1-server.py file, then run the part1-client.py file on the same device.
Once the two programs are connected, the client will prompt the user to send a message to the server.
When the server receives the message, it will prompt the user to send a message to the client.
Once the server has sent the message and the client has received it, both programs will terminate.


To run the project, fork it, and install it to your preferred computer. 
Use VS Code or any other coding platform to open it.

On Windows: 
Open Command Prompt and run part1-server.py file. Then split the terminal then run part1-client.py. (It is important that server file is ran before the client).
Once the two programs are connected, the client will prompt the user to send a message to the server.
When the server receives the message, it will prompt the user to send a message to the client.
Once the server has sent the message and the client has received it, both programs will terminate.
